```
《关于印发中央国家机关、事业单位工作人员差旅费开支的规定>的通知》
        │  2007-01-01 废止
        ▼
财行〔2006〕313 号  《中央国家机关和事业单位差旅费管理办法》
  2006-11-13 印发 · 2007-01-01 施行 · 八章二十八条
        │  2014-01-01 废止（被 531 号第三十三条明文废止）
        ▼
财行〔2013〕531 号  《中央和国家机关差旅费管理办法》        ← 现行
  2013-12-31 印发 · 2014-01-01 施行 · 八章三十三条
        │  标准细化（不是废止关系）
        ▼
财行〔2015〕497 号  《关于调整中央和国家机关差旅住宿费标准等有关问题的通知》
        │  按 497 号的规定，把标准汇总成明细表
        ▼
财行〔2016〕71 号  《中央和国家机关工作人员赴地方差旅住宿费标准明细表》
  2016-04-01 印发 · 2016-05-01 执行
```

### 节点的性质要分清

| 文号 | 与前一版的关系 | 对规则库意味着什么 |
| --- | --- | --- |
| 财文字〔1996〕2 号 | 被废止 | 超出本项目范围，不建档 |
| 财行〔2006〕313 号 | **被废止** | 用于版本对比，规则要带 `effective_to: 2013-12-31` |
| 财行〔2013〕531 号 | **替代** 2006 版 | 规则主体，`effective_from: 2014-01-01` |
| 财行〔2015〕497 号 | **调整标准**（非废止） | 需核实它改了哪些标准，是否已被 71 号覆盖 |
| 财行〔2016〕71 号 | **细化/汇总标准**（非废止） | 住宿费阈值的当前依据，`effective_from: 2016-05-01` |

**「废止」「替代」「细化」「补充」是不同性质的变更**，对规则库的处理方式不一样：
被废止的要关闭生效区间，被细化的要更新阈值但保留条款来源。

## 二、版本差异清单

找差异的方法：**按章对照**，而不是通读全文找不同。两版都是八章，
但章节划分和条文内容都有变化，逐章对一遍不容易漏。

每条差异按下面的模板记，**关键是「两边的条款号」都要写出来**——
指不到具体条款的差异不算数，因为规则库里没法用它。

### 差异记录模板

```markdown
### 差异 N：<一句话说清变了什么>

| | 2006 版（财行〔2006〕313 号） | 2013 版（财行〔2013〕531 号） |
| --- | --- | --- |
| 条款 | 第 X 条 | 第 Y 条 |
| 原文 | <摘录> | <摘录> |
| 实质变化 | <是数额变了？范围变了？后果变了？还是整条删了？> |

**对规则库的影响**：<要拆成两条规则？还是改阈值？还是删除规则？>
**能否构造演示用例**：<同一份申请在两版下结论不同的具体例子>
```

### 差异 1（范例，已填写）

**公杂费改为市内交通费，金额上调，用途收窄。**

| | 2006 版 | 2013 版 |
| --- | --- | --- |
| 条款 | 第十五条 | 第二十条 |
| 原文 | 「出差人员的**公杂费**按出差自然（日历）天数实行定额包干，每人每天 **30 元**，用于补助**市内交通、通讯等支出**。」 | 「**市内交通费**按出差自然（日历）天数计算，每人每天 **80 元**包干使用。」 |
| 实质变化 | 三项：**类别改名**（公杂费→市内交通费）、**金额 30→80**、**用途收窄**（去掉「通讯等」） |

**对规则库的影响**：不能只改阈值。类别名变了，意味着规则的条件字段取值也变了——
如果申请数据里出现「通讯费」，在 2013 版下没有对应类别，会落进**缺口**（这正是诊断层要发现的东西）。

**能否构造演示用演例**：能。一份含「公杂费 50 元」的模拟申请——
在 2006 版规则下判「在 30 元包干内，超支自理」，在 2013 版规则下该类别不存在，要判「未知类别，转人工」。

## 三、找差异的线索

按章对照，下面这些位置值得重点看。**我没有告诉你答案，只指了位置。**

| 对照范围 | 为什么值得看 |
| --- | --- |
| 两版**第二章**（城市间交通费） | 对比交通工具等级表；另外注意 2006 版里有一条关于**卧铺票补助**的规定，2013 版还有没有？ |
| 两版**第三章**（住宿费） | 2006 版有「**定点住宿**」的概念和对不同级别的具体房型规定（注意「处级以下」住什么），2013 版怎么变的？标准由谁定、按什么流程定，两版一样吗？ |
| 两版**住宿费发票的规定** | 2006 版和 2013 版都有「无发票怎么办」的条款，**但后果范围不一样**——仔细看 2013 版多列了几项费用 |
| 两版**伙食补助费** | 2006 版直接写死了金额，2013 版还是写死吗？接待单位安排伙食的情形，两版的处理一样吗？ |
| 两版**章节目录** | 数一数章名。**2006 版有一整章在 2013 版里找不到了**——先确认是不是真的删了，再想为什么删 |
| 两版**适用范围**（第二条） | 2006 版写的是「中央国家机关和事业单位」，2013 版呢？参照执行的范围有没有变化？ |
| 两版**会议相关规定** | 2006 版里有一条关于「小型调查研究会等不统一安排食宿」的例外，2013 版还有吗？ |
| 两版**附则** | 注意 2013 版第三十三条和 2006 版第二十七条的废止关系写法 |

## 四、待核实的疑点

写进这里就别忘了——这些会影响规则库的正确性。

1. **财行〔2015〕497 号到底改了什么标准？** 它和 71 号明细表是什么关系，
   是 71 号已经吸收了 497 号的内容，还是 497 号另有独立规定需要单独建档？
2. **531 号在 2016 年之后是否还有标准调整通知？** 未穷尽核实。
3. **伙食补助费的标准表**仍未获取。531 号第十七条说标准由财政部统一发布（见附表），
   但 gov.cn 公报文本里附表标注为「略」。这意味着**规则库暂时覆盖不了伙食补助费的金额标准**——
   这条边界要写在文档里。
4. **2006 版第六条和 2013 版第七条的交通工具等级表**内容是否完全一致？
   存档文本里表格的排版可能不完整，需要逐格比对而不是目测。
