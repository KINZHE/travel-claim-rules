### 节点的性质要分清

| 文号 | 与前一版的关系 | 对规则库意味着什么 |
| --- | --- | --- |
| 财文字〔1996〕2 号 | 被废止 | 超出本项目范围，不建档 |
| 财行〔2006〕313 号 | **被废止** | 用于版本对比，规则带 `effective_to: 2013-12-31` |
| 财行〔2013〕531 号 | **替代** 2006 版 | 规则主体，`effective_from: 2014-01-01` |
| 财行〔2015〕497 号 | **调整标准**（非废止） | 住宿费阈值的一次调整，并引入淡旺季试行与上浮比例 |
| 财行〔2016〕71 号 | **细化/汇总**（非废止） | 住宿费阈值的当前依据，细化到地市 |
| 财办行〔2019〕104 号 | **补充执行口径**（非废止） | 把「向接待单位交费」从义务变成可计算的百分比 |

**「废止」「替代」「调整」「细化」「补充」是不同性质的变更**，对规则库的处理方式不一样：
被废止的要关闭生效区间；被调整、细化的要更新阈值但保留条款来源；
被补充的要在原条款下挂新的执行细则。

### 现已确认的结论

**531 号在 2016 年之后确实还有配套文件**——财办行〔2019〕104 号。
原计划里「531 号是否有后续调整」这个待核实项，答案是**有**，且已建档。

注意 104 号的**性质与 497、71 不同**：后两者改的是**住宿费阈值**，
104 号改的是**伙食费和市内交通费的收交口径**（谁向谁交钱、按什么比例），
不改标准本身。三份文件在规则库里的挂载位置不一样。

## 二、版本差异清单

找差异的方法：**按章对照**，而不是通读全文找不同。两版都是八章，
但章节划分和条文内容都有变化，逐章对一遍不容易漏。

每条差异按下面的模板记，**关键是「两边的条款号」都要写出来**——
指不到具体条款的差异不算数，因为规则库里没法用它。

### 差异记录模板

```markdown
### 差异 N：<一句话说清变了什么>

| | 2006 版（财行〔2006〕313 号） | 2013 版（财行〔2013〕531 号） |
| --- | --- | --- |
| 条款 | 第 X 条 | 第 Y 条 |
| 原文 | <摘录> | <摘录> |
| 实质变化 | <是数额变了？范围变了？后果变了？还是整条删了？> |

**对规则库的影响**：<要拆成两条规则？还是改阈值？还是删除规则？>
**能否构造演示用例**：<同一份申请在两版下结论不同的具体例子>
```

### 差异 1：公杂费改为市内交通费，金额上调，用途收窄

| | 2006 版 | 2013 版 |
| --- | --- | --- |
| 条款 | 第十五条 | 第二十条 |
| 原文 | 「出差人员的**公杂费**按出差自然（日历）天数实行定额包干，每人每天 **30 元**，用于补助**市内交通、通讯等支出**。」 | 「**市内交通费**按出差自然（日历）天数计算，每人每天 **80 元**包干使用。」 |
| 实质变化 | 三项：**类别改名**（公杂费→市内交通费）、**金额 30→80**、**用途收窄**（去掉「通讯等」） |

**对规则库的影响**：不能只改阈值。类别名变了，意味着规则的条件字段取值也变了——
如果申请数据里出现「通讯费」，在 2013 版下没有对应类别，会落进**缺口**（这正是诊断层要发现的东西）。

**能否构造演示用例**：能。一份含「公杂费 50 元」的模拟申请——
在 2006 版规则下判「在 30 元包干内，超支自理」，在 2013 版规则下该类别不存在，要判「未知类别，转人工」。

### 差异 2：住宿费无发票的后果，从「不报住宿费」扩大到「四项全不报」

| | 2006 版 | 2013 版 |
| --- | --- | --- |
| 条款 | 第十二条 | 第二十五条（后半句） |
| 原文 | 「出差人员无住宿费发票，**一律不予报销住宿费**。」 | 「**实际发生住宿**而无住宿费发票的，不得报销**住宿费以及城市间交通费、伙食补助费和市内交通费**。」 |
| 实质变化 | **后果范围从 1 项扩大到 4 项**；同时**新增前置条件「实际发生住宿」** |

**两个变化性质不同，必须分开看**：

- 后果扩大 = 扣得更多了
- 前置条件 = 触发条件变窄了。新版只在**确实住了但没发票**时才扣四项；
  没住宿的情形根本不触发

**对规则库的影响**：不能简单改数值。这条是**联动规则**——一个字段影响四项费用，
是最容易写漏的一类。而且旧版规则在新版下**不能复用**：
旧版「无发票→扣住宿费」在新版下会误伤「没住宿也没发票」的申请。

**能否构造演示用例**：能，而且是两个方向：

| 用例 | 2006 版结论 | 2013 版结论 |
| --- | --- | --- |
| 住了 3 晚，缺住宿发票 | 不报住宿费，其余三项照报 | **四项全不报** |
| 没住宿（当天往返），自然也没有住宿发票 | 按字面「无发票」扣住宿费（实际扣 0，但逻辑上会走到该规则） | 前置条件不成立，**规则不触发**，其余三项正常 |

第二个用例尤其适合演示：**同一份申请，两条规则的触发与否不同，而按旧版逻辑会多走一步。**

### 差异 3：取消定点住宿，房型与级别规定重写

| | 2006 版 | 2013 版 |
| --- | --- | --- |
| 条款 | 第十条、第十一条 | 第十三条、第十四条 |
| 原文 | 第十条：「中央国家机关工作人员出差**实行定点住宿**。住宿标准：**副部长级**人员住套间，司局级人员住标准间，**处级以下人员两人住一个标准间**。」<br>还规定「出差人员**必须到定点饭店住宿**」「因特殊情况未到定点饭店住宿的，在出差地住宿费开支标准上限以内凭据报销」「定点饭店通过招标、协商方式确定，名单另行公布」<br>第十一条：事业单位**暂不实行**定点住宿 | 第十三条：「**部级**及相当职务人员住普通套间，司局级及以下人员住**单间或标准间**。」<br>第十四条：「应当在职务级别对应的住宿费标准限额内，**选择安全、经济、便捷的宾馆住宿**。」 |
| 实质变化 | **四件事**：① 定点住宿制度取消；② 「处级以下两人一间」取消，改为「单间或标准间」；③ 新增「在限额内自行选择」；④ 级别名「副部长级」→「部级」 |

**对规则库的影响**：这是**整条作废**，不是改阈值。

- 「是否到定点饭店住宿」这个判断在 2013 版**完全不存在**——2006 版的对应规则整条删除
- 「处级以下两人一间」的房型规则也删除
- 新增的「在限额内选择」由住宿费限额规则（第十三条/第十四条 + 71 号明细表）承接

**注意还有第三层变化**：财行〔2015〕497 号第三条进一步规定「**不分房型**」，
把 2013 版第十三条的房型要求也取消了。所以这条规定的演变是**三段**：

```
定点饭店 + 两人一间（2006）
    → 取消定点、单间或标准间（2013）
    → 连房型也不分（2015 / 497 号）
```

第三段与第二段冲突且两份文件都现行有效，见 `ambiguity-log.md` A-012。

**能否构造演示用例**：能。

| 用例 | 2006 版 | 2013 版 |
| --- | --- | --- |
| 处级人员住非定点饭店，价格在限额内 | 「未到定点饭店」，需走特殊情况说明 | 不受限制，只要在限额内即通过 |
| 处级人员住单间 | 「处级以下两人一间」，单间不合规 | 允许（单间或标准间） |
| 部级人员住套间 | 「副部长级住套间」，允许 | 「部级住普通套间」，允许 |

### 差异 4：伙食补助费的金额从正文移入附表，「凭收据报销」机制取消

| | 2006 版 | 2013 版 |
| --- | --- | --- |
| 条款 | 第十三条、第十四条 | 第十六条、第十七条、第十八条 |
| 原文 | 第十三条：「伙食补助费按出差自然（日历）天数实行定额包干，**每人每天 50 元**。」<br>第十四条：「由接待单位统一安排伙食的，**不实行包干办法**……每人每天在 **50 元以内凭接待单位收据据实报销**。」 | 第十六条：「按出差自然（日历）天数计算，**按规定标准包干使用**。」（无数字）<br>第十七条：标准由各省提出、报财政部，经财政部统筹研究后「**由财政部统一发布**……（见附表）」<br>第十八条：「应当自行用餐。凡由接待单位统一安排用餐的，应当向接待单位**交纳伙食费**。」（无金额、无报销） |
| 实质变化 | ① **金额从正文移出**，改为「按标准」+ 附表；② **「50 元以内凭收据报销」的机制取消**；③ 接待单位安排用餐的情形，从「可报销」改为「应自行承担并交费」 |

**对规则库的影响**：**这条差异直接造成了本项目的覆盖缺口。**

531 号正文里根本没有伙食补助费的数额，而 gov.cn 公报文本的附表标注为「略」。
所以规则库要写这条，只能依赖另找的附表；而**正式发布的附表至今未取得 A 层级原件**
（`sources/SOURCES.md` 第五节）。

**能否构造演示用例**：这条**不适合**做成「两版结论不同」的演示，因为 2006 版的 50 元
不是 2013 版 100 元的直接前身（中间还有各省细化）。诚实地说：这条的价值不在于演示，
而在于**解释规则库为什么缺一块**。

> 这也是按章比对能发现、按条文检索发现不了的东西：**数字消失了**。
> 只看 2013 版永远不会知道这里曾经有个数。

### 差异 5：公杂费「减半发放」改为「向对方交费」——机制反转

| | 2006 版 | 2013 版 |
| --- | --- | --- |
| 条款 | 第十六条 | 第二十一条 |
| 原文 | 「出差人员由**所在单位、接待单位或其他单位免费提供交通工具**的，应如实申报，**公杂费减半发放**。」 | 「出差人员由**接待单位或其他单位提供交通工具**的，**应向接待单位或其他单位交纳相关费用**。」 |
| 实质变化 | **逻辑方向反转**：旧版是「少发你钱」，新版是「你付别人钱」。且旧版含「所在单位提供」，新版没有这一项 |

**对规则库的影响**：这不是改数值，是**换了一套计算逻辑**。

- 2006 版：`公杂费 = 30 × 天数 × (0.5 if 免费提供交通工具 else 1)`
- 2013 版：`市内交通费 = 80 × 天数`（**不因提供交通工具而减少**），
  另有一条独立的「向对方交费」规则，具体比例由 104 号补充

**关键点**：2013 版下，接待方提供交通工具**不会**让当事人少拿市内交通费——
两件事是平行的。按 2006 版逻辑实现会算错。

**能否构造演示用例**：能。

| 用例 | 2006 版 | 2013 版 |
| --- | --- | --- |
| 接待单位免费提供交通工具，出差 3 天 | 公杂费 = 30 × 3 × 0.5 = **45 元** | 市内交通费 = 80 × 3 = **240 元**，另按 104 号向接待单位交费 |

### 差异 6：交通杂费与保险的报销范围调整

| | 2006 版 | 2013 版 |
| --- | --- | --- |
| 条款 | 第八条 | 第九条、第十条 |
| 原文 | 「乘坐飞机，**往返机场的专线客车费用、民航机场管理建设费**和航空旅客人身意外伤害保险费（限每人每次一份），凭据报销。」 | 第九条：「乘坐飞机的，**民航发展基金、燃油附加费**可以凭据报销。」<br>第十条：「乘坐**飞机、火车、轮船**等交通工具的，每人次可以购买交通意外保险一份。**所在单位统一购买交通意外保险的，不再重复购买。**」 |
| 实质变化 | ① 「民航机场管理建设费」→「民航发展基金」（改名），新增「燃油附加费」；② **「往返机场专线客车费用」不再列举**；③ 保险范围从**飞机**扩到**飞机/火车/轮船**；④ 新增「单位统一购买不重复」的限制 |

**对规则库的影响**：可报销项目清单变了，属于**类别枚举的增删**。

- 「机场专线客车费」在 2013 版没有对应项——按 2006 版实现会多报一项
- 保险从单一项变成有条件的多项（需判断单位是否统一购买）

**能否构造演示用例**：能。

| 用例 | 2006 版 | 2013 版 |
| --- | --- | --- |
| 申报「机场大巴 30 元」 | 属「往返机场专线客车费用」，**可报** | 不在列举范围 → 应输出「需人工确认」或按市内交通处理 |
| 申报「火车行程的意外险」 | 不属于（旧版只限飞机），**不可报** | **可报** |

### 差异 7：人员级别口径变化——枚举值不同，规则不能直接复用

| | 2006 版 | 2013 版 |
| --- | --- | --- |
| 条款 | 第六条等级表、第十条 | 第七条等级表、第十三条 |
| 原文 | 「**副部长级**人员住套间，司局级人员住标准间，**处级以下**人员两人住一个标准间」 | 「**部级**及相当职务人员住普通套间，司局级及以下人员住单间或标准间」 |
| 实质变化 | 级别枚举值变了：**副部长级 → 部级**；**处级以下 → 其余人员** |

**对规则库的影响**：这是**最容易被忽略、后果最直接**的一条。

- `scope.person_level` 的取值集不同：2006 是 `{副部长级, 司局级, 处级以下}`，
  2013 是 `{部级, 司局级, 其余人员}`
- 同一份写着「处级」的申请，在 2006 版要映射到「处级以下」，在 2013 版要映射到「其余人员」
- 如果规则里硬编码了旧枚举值，切换到新版后**所有规则都匹配不上**，
  而且失败方式很隐蔽——不会报错，只是全部落进「缺口」

**数据限制（必须说明）**：2006 版的交通等级表在**两个来源里都标注为「（略）」**，
表格本身不在存档文本中。所以只能比对条文叙述，**表格无法逐格核对**。
这一条是真实的来源限制，不能因为「应该有」就当它一致。

**能否构造演示用例**：能，但演示的是**匹配失败**而不是结论不同：

| 用例 | 2006 版 | 2013 版 |
| --- | --- | --- |
| 人员级别字段填写「处级」 | 匹配到「处级以下」 | 需映射到「其余人员」；若映射缺失 → 无规则命中 → **缺口** |

### 差异 8：卧铺补助与乘机审批 —— 整条删除

| | 2006 版 | 2013 版 |
| --- | --- | --- |
| 条款 | 第七条；第六条（二） | **无对应条款** |
| 原文 | 第七条：「乘坐火车……可购同席卧铺票。符合规定而未购买卧铺票的，**按实际乘坐的硬座票价的 80％ 给予补助**。可以乘坐软卧而改乘硬卧的，不再给予补助。」<br>第六条（二）：「出差人员乘坐飞机要从严控制……经单位**司局以上领导批准**方可乘坐飞机。」 | 第二章（第六条至第十条）只有：费用定义、等级表、选乘原则、民航基金与燃油附加费、保险。**没有卧铺补助，也没有乘机审批** |
| 实质变化 | **两条可计算的补贴/审批规则被整条删除** |

**对规则库的影响**：不是「变了」，是「没了」。

- 若规则库只实现 2013 版，处理 2013 年之前的历史申请时会**找不到规则**
- 这正是需要 `effective_to` 字段的原因：旧规则不能删，只能关闭生效区间
- 系统必须能区分「**没有规则**」和「**规则说可以**」——前者应输出「制度未覆盖」，
  后者才是「通过」。混为一谈会把漏洞伪装成合规

**能否构造演示用例**：能，演示**缺失规则**的两种处理：

| 用例 | 2006 版 | 2013 版 |
| --- | --- | --- |
| 符合条件未购卧铺，硬座票价 200 元 | 补助 160 元 | 无此规则 |
| 未经司局级领导批准乘飞机 | 不合规 | 无此要求（第七条只管等级） |

### 差异 9：章节目录重组 —— 一整章被删除

| | 2006 版 | 2013 版 |
| --- | --- | --- |
| 章节数 | 8 章 28 条 | 8 章 33 条 |
| 章名对照 | 总则 / 城市间交通费 / 住宿费 / 伙食补助费 / **公杂费** / **参加会议等的差旅费** / **调动、搬迁的差旅费** / 附则 | 总则 / 城市间交通费 / 住宿费 / 伙食补助费 / **市内交通费** / **报销管理** / **监督问责** / 附则 |
| 实质变化 | ① 公杂费章 → 市内交通费章；② 参加会议章**并入附则第三十条**；③ **调动、搬迁章整章删除**（2006 第五、六、七章含基层锻炼、部队转业等内容）；④ **新增**报销管理章、监督问责章 |

**对规则库的影响**：**范围收缩，不是遗漏**。

- 调动搬迁相关的费用判断（托运费、家属随迁）在 2013 版没有规则
- 基层锻炼期间「每人每天 15 元伙食补助」（2006 第十八条）也没有对应
- 规则库要把这些明确标为「**现行制度未覆盖**」，而不是当作不存在

> 「制度没规定」不等于「制度允许」。规则库的输出必须能表达第三种状态：
> **本申请涉及的事项，现行制度没有规定。**

**能否构造演示用例**：能。一份调动搬迁的申请——
2006 版有规则可判（托运费每人每公里 1 元以内凭据报销）；2013 版无规则，
应输出「制度未覆盖」，**不能输出「通过」**。

### 差异 10：适用范围收窄，从「全部事业单位」到「参照公务员法管理的」

| | 2006 版 | 2013 版 |
| --- | --- | --- |
| 条款 | 第二条 | 第二条、第三十一条 |
| 原文 | 「本办法适用于**中央国家机关和事业单位**，包括中央驻北京市以外地区的国家机关和事业单位。」 | 第二条：「适用于中央和国家机关，以及**参照公务员法管理的事业单位**（以下简称中央单位）。」<br>第三十一条：「**不参照公务员法管理的事业单位参照本办法执行。**」 |
| 实质变化 | 强制适用范围**收窄**；不参照公务员法管理的事业单位从「适用」改为「参照执行」（可另定细则） |

**对规则库的影响**：新增一个外部属性——**该单位是否参照公务员法管理**。
没有这个属性，就无法判断某份申请是「必须按本办法判」还是「参照执行」。

**能否构造演示用例**：能。某不参照公务员法管理的事业单位提交申请——
2006 版：强制适用；2013 版：参照执行，本单位可能有自己的细则，
应输出「需按本单位规定确认」而不是直接套用本办法。

## 三、比对方法（做完之后回头记的）

方法是**按章对照**，不是通读全文找不同。两版都是八章，但章节划分和条文内容都变了，
逐章对一遍不容易漏。具体做法：

1. 把两版按章拆开，同一主题的章节并排放
2. 逐条读旧版，在对应主题的新版章节里找「有没有对应」
3. 三种结果都要记：
   - **有对应但内容变了** → 记差异（改了什么）
   - **有对应但整条没了** → 记删除（差异 8）
   - **整个主题没了** → 记范围收缩（差异 9）
4. 对每条差异问三句：**数额变了？范围变了？后果变了？**

### 按章对照时最容易漏的三类变化

| 类型 | 为什么容易漏 | 实例 |
| --- | --- | --- |
| **数字消失了** | 只看新版永远不知道这里曾有数字 | 差异 4：50 元/天从正文移入附表 |
| **机制反转了** | 文义上看都是「提供交通工具」相关，句子也像 | 差异 5：减半发放 → 向对方交费 |
| **枚举值改名了** | 数值可能一样，规则却匹配不上 | 差异 7：处级以下 → 其余人员 |

第三类尤其隐蔽：它不产生「结论不同」，只产生「**匹配失败**」，
而匹配失败在系统里往往表现为「没有规则适用」，不会报错。

### 这次比对受限于来源的地方

- **2006 版交通等级表**在两个来源里都标注「（略）」，表格本身不在存档文本中，
  所以差异 7 只能比对条文叙述，**无法逐格核对表格**
- **2013 版附表**标注「略，详情请登录财政部网站」，伙食补助费的标准不在正文里（差异 4）

这两处都是**来源限制**，不是没做。写进文档比假装核对过要好。
